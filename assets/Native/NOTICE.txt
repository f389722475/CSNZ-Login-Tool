CSNZ Launcher Native Components

The login bridge and Class Awakening retain their existing implementations.
Weapon repairs are now in weapon-mods/: one shared native C++ server core and
named per-weapon selection modules. The old client-side GigaBreakLE 0.7.4 is not
included or loaded by this build.

MinHook v1.3.4 (x86 subset):
https://github.com/TsudaKageyu/minhook/tree/v1.3.4
See MinHook-LICENSE.txt and weapon-mods/shared/third_party/minhook/LICENSE.txt.

The first-party mod source has not been assigned a new open-source license.
This local build includes an overlay prepared from the user's installed-game
assets. It is not a public redistribution package and must not be published.
